# GalleryHopper 🗽

A Python app to search art galleries and exhibitions in New York City.

## About
GalleryHopper was created to make it easier to find art galleries and museums in NYC, 
filtering by neighborhood, art style, and more. 
Built as part of a Data Structures course, using a Binary Search Tree (BST) to organize and search galleries efficiently.

## Features
- Search gallery by name
- Filter by neighborhood
- Filter by art style
- List all galleries and museums
- Browse all art styles with clickable options

## Tech Stack
- Python 3.12
- tkinter (GUI)
- Binary Search Tree (BST)
- Object-Oriented Programming (OOP)

## Project Structure
- `node.py` — Node class
- `bst.py` — Binary Search Tree class
- `data.py` — Gallery and museum data
- `main.py` — Terminal menu
- `app.py` — tkinter interface
