# GalleryHopper 🗽

A Python desktop app to search art galleries and museums in New York City.

## About
GalleryHopper was created to make it easier to discover art spaces in NYC — filtering by neighborhood, art style, and more. Built as part of a Data Structures course, using a Binary Search Tree (BST) implemented from scratch to organize and search galleries efficiently.

## Features
- Search gallery or museum by name (with alias support — search "MET", "MoMA", "Whitney")
- Browse by neighborhood
- Browse by art style
- List all galleries and museums
- Detail screen with location, art styles, and upcoming features

## Tech Stack
- Python 3.12
- tkinter (GUI)
- Binary Search Tree (BST) — implemented from scratch
- Object-Oriented Programming (OOP)
